## About me

I'm based in Italy and I like making practical, slightly chaotic projects: local tools, static sites, experiments, and whatever sounds fun enough to build on a Saturday evening.

Right now I mostly play with:

- C# / .NET and Godot for games (tIndustry)
- Rust + Tauri for desktop tools (Diff_Local)
- JavaScript for web experiments and GitHub Pages projects
- Python for local utilities and converters
- PowerShell for scripts and automation
- Static (and dynamic) sites, small tools, and content dashboards
